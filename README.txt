DIGITAL SMART - CYBER MISSION (5 LEVEL)

ISI PAKET
- index.html : halaman game
- style.css  : desain dan tampilan
- script.js  : sistem permainan dan 25 soal tingkat lanjut berbasis skenario

STRUKTUR
- 5 level dengan tema berbeda
- Masing-masing level berisi 5 soal
- Total 25 soal, nilai maksimal 100 poin
- Pertanyaan dirancang lebih menantang dengan kasus dan pilihan jawaban yang lebih mirip

CARA MENJALANKAN
1. Ekstrak ZIP ke satu folder.
2. Pastikan index.html, style.css, dan script.js berada di folder yang sama.
3. Buka index.html menggunakan browser (Chrome, Edge, Firefox, atau browser lain).

Alternatif: gunakan file Digital_Smart_5_Level.html untuk versi satu file.
Versi satu file dapat dibuka langsung tanpa mengekstrak ZIP.
Koneksi internet hanya diperlukan untuk memuat Google Fonts; game tetap dapat dimainkan tanpa font tersebut.
